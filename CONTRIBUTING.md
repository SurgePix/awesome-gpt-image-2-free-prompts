# Contributing to Awesome GPT Image 2 Free Prompts

Thank you for helping grow this library! Here's how to contribute.

---

## Adding Prompts

1. **Fork** this repository
2. **Find the right file** in `docs/categories/` — or propose a new category
3. **Add your prompt** following the format below
4. **Submit a Pull Request** with the title format: `[category] Add [short description]`

### Prompt Format

Every prompt entry should look like this:

```markdown
### [Short Descriptive Title]
```
[The full prompt text here]
