1. Salin prompt apa saja dari perpustakaan
2. Tempelkan ke ChatGPT (dengan GPT-Image-2 aktif) atau OpenAI Images API
3. Sesuaikan parameter sesuai kebutuhan

## 📌 Tentang GPT-Image-2

GPT-Image-2 adalah model pembuatan gambar terbaru dari OpenAI, dikenal dengan:

- Rendering teks dalam gambar yang luar biasa
- Komposisi multi-elemen yang kompleks
- Mengikuti instruksi detail dengan presisi
- Poster, infografis, mockup UI, dan lembar karakter berkualitas tinggi

Pelajari lebih lanjut: [Panduan GPT-Image-2 oleh SurgePix](https://surgepix.ai/blog/resources/chatgpt-images-2-0)
