**方法 1 — ウェブサイトを使う（推奨）**
1. [surgepix.ai/resources/gpt-image-2-prompts](https://surgepix.ai/resources/ja/gpt-image-2-prompts) にアクセス
2. カテゴリで閲覧・絞り込み
