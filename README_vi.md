## 🚀 Cách Sử Dụng

**Cách 1 — Dùng website (khuyến nghị)**
1. Truy cập [surgepix.ai/resources/gpt-image-2-prompts](https://surgepix.ai/resources/vi/gpt-image-2-prompts)
2. Duyệt hoặc lọc theo danh mục
3. Nhấn **Sao chép** để lấy prompt, hoặc **Tạo ảnh** để tạo trực tiếp

**Cách 2 — Dùng trong ChatGPT / OpenAI API**
1. Sao chép bất kỳ prompt nào từ thư viện
2. Dán vào ChatGPT (cần bật GPT-Image-2) hoặc OpenAI Images API
3. Điều chỉnh tham số theo nhu cầu

## 📌 Về GPT-Image-2

GPT-Image-2 là mô hình tạo ảnh mới nhất của OpenAI, nổi bật với:

- Khả năng hiển thị văn bản trong ảnh xuất sắc
- Bố cục phức tạp nhiều thành phần
- Tuân theo chỉ dẫn chi tiết chính xác
- Poster, infographic, UI mockup và character sheet chất lượng cao

Tìm hiểu thêm: [Hướng dẫn GPT-Image-2 của SurgePix](https://surgepix.ai/blog/resources/chatgpt-images-2-0)
