## Consistency Prompts

Use these templates when generating the same character in multiple scenes.

### Base Character Description Template
```
[CHARACTER NAME]: [AGE]-year-old [GENDER], [HAIR COLOR/STYLE], 
[EYE COLOR], [HEIGHT/BUILD], wearing [SIGNATURE OUTFIT]. 
Distinctive features: [UNIQUE DETAIL]. 
Keep these features consistent across all scenes.
```

### Scene Variation Template
```
[PASTE BASE CHARACTER DESCRIPTION]. 
New scene: [LOCATION], [TIME OF DAY], [ACTION].
Same character design as described — do not alter appearance.
[STYLE/MEDIUM] style.
```
